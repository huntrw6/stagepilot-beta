# Private beta release 1 — v1.1.103-beta.3

## Summary

First signed StagePilot private beta for Windows x64, macOS Apple Silicon, and macOS Intel.

## Included

- Transparent private-beta Remote enrollment with per-machine native credentials.
- Stable HTTPS/WSS Remote access and Viewer/Operator authorization.
- Signed installers for all three targets, verified by the Tauri updater signing key.

## Known limits

- In-app update is off for this beta: the release broker is not deployed, so a
  newer build is delivered as a fresh installer download, not an Update button.
- Windows publisher signing and Apple notarization are not part of this community beta.
- Fresh-machine, reboot, Gatekeeper/SmartScreen, and in-app update acceptance must be recorded separately.

## Verification

Attach the asset inventory generated by `node scripts/audit_beta_release.mjs assets release-assets 1.1.103-beta.3`. Do not paste secrets or private machine state.
